# JC EDU 마케팅 WBS

JC EDU 마케팅팀 업무(WBS·대표님 REQ)를 함께 관리하는 웹 서비스입니다.
GitHub Pages에서 화면을 제공하고, 데이터는 Supabase(DB·로그인)에 저장합니다.

## 기능
- 업무 현황: 실제 진척 vs 오늘까지 계획, 지연·임박·확인 필요 건수, 담당자별 업무량, 이번 주 마감
- WBS / 대표님 REQ: 카테고리 → 상시 업무 → 하위 업무 3단계, 필터(담당자·상태·브랜드·일정 체크·내 업무), D-day·일정 체크 자동 계산
- 상세 편집: 상태·진척률·일정·산출물 링크·상시 업무 월 실적·대표님 보고 관리, 완료 시 진척률 100% 자동 반영
- 변경 이력: 누가 언제 무엇을 바꿨는지 자동 기록
- 실시간 반영: 다른 팀원이 수정한 내용이 바로 화면에 반영, 동시에 같은 업무를 고치면 덮어쓰기 방지
- 주간 보고: 기준일의 주간 지연 / 이번 주 마감 / 진행 중 / 지난주 완료 자동 추출, 보고 문구 복사
- 간트: 주 단위 일정 막대, 오늘 표시
- 엑셀 다운로드: WBS·대표님 REQ·변경 이력 시트가 든 .xlsx

## 권한
| role | 보기 | 편집·업무·카테고리 추가 | 삭제 |
|---|---|---|---|
| admin | O | O | 바로 삭제, 삭제 요청 승인·반려 |
| member | O | O | 삭제 요청만 (관리자 승인 후 삭제) |
| viewer | O | X | X |

`members` 테이블에 등록된(=관리자가 승인한) 계정만 로그인 후 데이터를 볼 수 있습니다 (DB의 RLS 정책으로 강제).

## 가입 · 로그인
- 로그인은 **이메일 + 비밀번호**만 사용합니다. 메일 링크 로그인은 없습니다.
- 새 팀원은 로그인 화면의 **회원가입**에서 이름·이메일·비밀번호를 입력 → 관리자가 **관리자 탭 → 가입 요청**에서 담당자 연결·권한을 정해 승인하면 사용할 수 있습니다.
- 승인 전에는 '가입 승인 대기 중' 화면만 보이고 데이터는 DB에서 차단됩니다.
- 비밀번호를 잊으면: 관리자가 '계정 삭제' → 다시 가입 → 승인 (담당자·업무 기록은 유지)

## 설치 (최초 1회)

### 1. Supabase
1. supabase.com 에서 새 프로젝트 생성 (Region: Northeast Asia (Seoul))
2. **SQL Editor**에서 `supabase/schema.sql` 실행
3. **SQL Editor**에서 초기 데이터 `seed.sql` 실행 — 저장소에 없는 별도 파일입니다. 팀원 이메일을 채운 뒤 실행하세요.
4. **Authentication → Sign In / Providers → Email**에서 **Confirm email 끄기** → Save
   (가입 시 확인 메일을 보내지 않고, 관리자 승인으로 대신합니다)
5. **Authentication → URL Configuration** — Site URL: `https://goochanbae.github.io/JCEDU/`
6. **Project Settings → API**에서 Project URL과 `anon` `public` 키를 복사

### 2. 코드 설정
`config.js`에 위에서 복사한 값을 넣습니다.
```js
window.JC_CONFIG = {
  SUPABASE_URL: 'https://xxxx.supabase.co',
  SUPABASE_ANON_KEY: 'eyJ...'
};
```
anon 키는 공개되어도 되는 키입니다. 데이터는 RLS 정책이 보호합니다. `service_role` 키는 절대 넣지 마세요.

### 3. GitHub Pages
저장소 **Settings → Pages** → Source: `Deploy from a branch`, Branch: `main` / `/ (root)` → Save
몇 분 뒤 `https://goochanbae.github.io/JCEDU/` 에서 열립니다.

## 관리자 페이지 (회원 관리)
관리자로 로그인하면 **관리자** 탭이 보입니다. (다른 권한에는 탭이 보이지 않고 주소로 들어와도 업무 현황으로 돌아갑니다. 데이터 수정 권한은 DB의 RLS가 막습니다)
- 가입 요청 승인(담당자 연결 + 권한) · 거절
- 회원 권한 변경, 계정 삭제 (담당자·업무 기록은 유지)
- 담당자 목록 편집, 최근 변경 이력

## 내 계정 · 비밀번호
모든 사용자는 상단 **내 계정**에서 비밀번호(8자 이상)를 바꿀 수 있습니다.

## 담당자 편집
- 담당자 추가·이름 변경·순서 변경·사용 끄기 (이름을 바꾸면 기존 업무의 PIC·Backup도 함께 변경)
- 로그인 계정 연결은 가입 승인에서만 합니다 (담당자 편집 화면에서는 보기만 가능)

## 일일보고
- **일일보고** 탭 → '내 보고 작성'
  - 01 전일 업무 결과: 최근 내 보고의 '금일 업무'가 자동으로 채워짐 → 실제 진행률만 고침 (100%면 완료, '컨펌 대기' 선택 가능)
  - 02 금일 업무 내용: 내 업무를 체크하고 목표 진행률 선택. 새 업무는 그 자리에서 추가(미분류함으로 등록), 업무 등록 없이 직접 입력도 가능
  - 03 이슈 / 요청사항: 이슈와 대응 방안. `@이름`을 쓰면 제출 시 알림
  - 04 이번 주 계획: **쓰지 않음.** 내 업무 목록에서 자동(이번 주 마감 + 진행 중). 지난 날짜는 빨갛게, 완료·날짜 변경을 바로 할 수 있음
  - **제출하기**: 전일 결과 진행률을 업무에 반영
  - **메신저 문구 복사**: 지금 쓰는 메신저 양식 그대로 문구만 복사 (제출과 별개)
  - **제출하고 엑셀 내려받기**: 제출까지 함께 처리한 뒤 `templates/daily_report.xlsx`(팀 일일보고 양식)에 자동 기입. 칸이 모자라면 같은 모양의 행을 추가하고, 수식·드롭다운·조건부 서식은 그대로
- '팀 일일보고': 날짜별 팀원 보고, 미제출 표시, 오늘 이슈 모아보기, 공동 업무(사람별 진척·완료일), 주간 정리 문구 복사, 사람별 문구·엑셀
- 업무 상세의 **일일 기록** 탭: 그 업무가 날짜별로 어떻게 보고됐는지
- 업무 **유형**: P 프로젝트 / R 반복(루틴) / 목표·R&R(일정 체크·일일보고 대상 아님). 상태에 **컨펌 대기** 추가
- 양식을 바꾸려면 `templates/daily_report.xlsx`를 같은 칸 배치로 교체 (01 전일 8~12행, 02 금일 17~21행, 03 이슈 25~27행, 04 이번 주 31~38행, 작성자 D4, 보고일 H4)

## 내 업무 (로그인 후 첫 화면)
- 내가 PIC인 업무를 지연 → 마감 가까운 순으로 보여줍니다. 지연·이번 주 마감·진행 중·업데이트 필요(진행 중인데 7일 넘게 그대로) 카드를 누르면 해당 업무만 걸러 봅니다.
- 완료한 업무는 목록에서 빠지고 아래 **완료한 업무**(최근 30일, 펼치기)로 따로 모이며 '다시 진행'으로 되돌릴 수 있습니다. 팀 현황도 업무량 막대·이번 주 마감은 진행 중인 업무만, 완료는 '완료' 수와 **완료한 업무**(최근 14일) 표로 따로 봅니다.
- 목록에서 바로 상태 변경, 진척률(0/25/50/75/100), 한 줄 메모(✎)를 남길 수 있고 모두 변경 이력에 기록됩니다.
- **보드** 보기: 카드를 예정·진행 중·보류·완료 칸으로 끌어 놓으면 상태가 바뀝니다.
- **+ 업무 등록**: 업무명만 있으면 등록됩니다. 위치(WBS 상위 항목)를 고르지 않으면 **미분류함**에 들어가고, 관리자가 업무 상세의 '상위 항목'으로 위치를 정리합니다.
- **체크리스트**: 업무 상세(또는 등록 화면)에서 할 일을 나눠 두면 체크한 비율이 진척률로 자동 계산됩니다. 없으면 직접 입력합니다.
- 오른쪽: 내가 Backup인 업무, 전원 업무, 내 업무 소식(최근 14일간 다른 사람이 바꾼 내용), 관리자에게는 미분류함
- **내 주간보고 복사**: 지난주 완료 · 진행 중 · 이번 주 마감 · 지연을 정리한 문구를 복사합니다.

### 알림 (모든 변경 사항)
- 오른쪽 위 **알림**에 최근 30일의 모든 변경이 쌓입니다: 업무 등록, 상태·진척률·체크리스트, 일정·마일스톤, 내용 수정(업무명·담당자·메모 등), 이동, 삭제 요청·삭제, 댓글·멘션, (관리자) 회원·담당자 관리.
- 분류 버튼(전체 · 멘션 · 댓글 · 새 업무 · 상태·진척 · 일정 · 내용 수정 · 이동 · 삭제 · 회원·담당자)으로 걸러 보고, 각 분류 옆 숫자는 안 읽은 건수입니다. '내 업무만', '내 변경 숨기기'로 더 좁힐 수 있습니다.
- 다른 사람의 변경은 안 읽음으로 표시되고, 업무를 열거나 알림을 누르면 읽음 처리됩니다. 내가 한 변경은 목록에만 보이고 숫자에는 넣지 않습니다.
- 화면 아래 알림·바탕화면 알림은 멘션, 내 업무 관련 변경, 새 업무, 삭제에만 뜹니다.
- 읽음 상태는 각자 브라우저에 저장됩니다. (메일은 보내지 않음)

### 새 소식 배지
- 내가 마지막으로 열어 본 뒤 다른 사람이 등록·수정·댓글을 단 업무에 **NEW** 배지가 붙습니다. 마우스를 올리면 무엇이 바뀌었는지(새 업무 / 새 댓글 N / 수정됨 · 누가) 보입니다.
- WBS·대표님 REQ 표, 내 업무 목록·보드, 오른쪽 목록, 간트(N 표시)에 표시되고, 카테고리 줄에는 'NEW N', 탭 이름 옆에는 개수가 뜹니다.
- 내가 바꾼 업무(내용 수정·등록·댓글)도 바꾼 뒤 24시간 동안 NEW가 붙습니다 (열어 봐도 유지).
- 다른 사람이 바꾼 업무는 내가 열어 보면 사라집니다. 표 위 **새 소식만**으로 모아 보거나 **새 소식 모두 확인**으로 한 번에 지울 수 있습니다.
- 확인 기록은 각자 브라우저에 저장되고, 처음 쓰는 날 이후의 변경부터 표시합니다.

### 댓글 · @멘션
- 업무 상세 창의 **댓글** 탭에서 진행 상황·질문·산출물 링크를 남깁니다 (입력칸은 창 아래 고정). 표·내 업무 목록의 댓글 버튼을 누르면 바로 댓글 탭이 열리고, 새 댓글이 있는 업무는 댓글 탭으로 열립니다. `https://` 링크는 자동으로 연결됩니다.
- `@`를 입력하면 담당자 목록이 뜨고, 고르면 그 사람에게 알림이 갑니다. `@전원`은 모든 담당자에게 알림.
- 내 업무(PIC·Backup·등록)에 달린 댓글도 알림으로 옵니다. 댓글은 팀원·관리자 누구나 어느 업무에나 달 수 있고, 삭제는 작성자·관리자만.

### 캘린더
- 월 단위 달력에 업무를 브랜드별 색으로 표시합니다. 여러 날 걸친 업무는 막대로 이어지고, 칸이 넘치면 '+N건 더보기'.
- 보기 탭: **캠페인·행사**(행사·단발 업무, 한 달 이내 업무, 마일스톤) / **단발 (P)** / **루틴 (R)** / **전체**(목표·상시 포함). 날짜는 크게, 업무 막대와 구분되는 날짜 줄로 표시.
- 구분(WBS/REQ) · 담당자(내 업무 포함) · 브랜드로 거를 수 있습니다.

### 간트 편집 · 마일스톤
- 수정 권한이 있는 업무는 막대를 끌어 일정을 옮기고, 양 끝을 끌어 시작일·마감일을 바꿀 수 있습니다. 변경은 이력에 남습니다.
- 확대·축소: 날짜 줄 위에서 마우스 휠 또는 어디서든 Ctrl(⌘)+휠(트랙패드 핀치 포함). 가리킨 날짜 기준으로 기간이 늘고 줄어듦. 빠른 선택: 분기 / 월 / 주, '내 업무만', '오늘로'.
- 업무 상세에서 **마일스톤**을 켜면 행사일·런칭일처럼 End 날짜에 ◆로 표시됩니다 (간트·캘린더).

### 수정 권한
- 관리자: 모든 업무
- 팀원: 내가 PIC·Backup이거나 직접 등록한 업무, '전원' 업무만 수정 (DB 트리거로 강제). 남의 업무는 보기 전용
- 보기 전용: 수정 불가

## 업무 위치 옮기기 (WBS · 대표님 REQ)
- 업무 줄을 끌어서 다른 줄에 놓으면 옮길 수 있습니다. 놓는 위치: 줄 위쪽 = 그 업무 **앞**, 아래쪽 = **다음**, 가운데 = 그 업무의 **하위로**, 카테고리 줄 = 그 카테고리 **맨 아래**.
- 놓으면 '기존 위치 → 새 위치' 확인 창이 뜨고, **옮기기**를 눌러야 반영됩니다. 하위 업무는 함께 옮겨지고 번호는 순서대로 다시 매겨집니다.
- 업무 단계는 카테고리 아래 **업무 → 하위 업무 → 세부 업무** 3단계까지. 하위 업무 상세에서 '+ 이 업무 아래에 세부 업무 추가'.
- 옮길 수 없는 곳(자기 하위, 3단계 초과, 다른 시트)은 빨갛게 표시됩니다. 팀원은 수정 권한이 있는 업무만 옮길 수 있습니다.

## 화면 사용 팁
- **열 순서 바꾸기**: WBS·대표님 REQ 표에서 '업무' 뒤의 열 제목을 끌어서 좌우로 옮길 수 있습니다. 순서는 각자 브라우저에 저장되며 '열 순서 초기화'로 되돌립니다.
- **카테고리 추가·이름 변경**: 표 위 '+ 카테고리 추가', 카테고리 줄의 '편집'
- **상위 항목 이동**: 업무 상세의 '상위 항목'을 바꾸고 저장하면 그 카테고리·업무 아래로 옮겨지고 번호가 다시 매겨집니다.
- **삭제 대기**: 팀원의 삭제 요청은 '삭제 대기'로 표시되고, 업무 현황의 '삭제 대기' 카드에서 모아볼 수 있습니다.
